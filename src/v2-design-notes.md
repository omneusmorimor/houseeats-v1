# HouseEats V2 — design foundation

## Product direction
A mobile-first hospitality app: sleek, modern, refined, warm without looking rustic or corporate.

## Member navigation
Home · Menu · Late Plate · Alerts · Profile

RSVP is intentionally removed.

## Visual principles
- Neutral canvas with high-contrast typography.
- One restrained brand accent; no neon palette.
- Professional Lucide iconography; no emoji UI.
- Editorial meal presentation instead of dashboard cards.
- Generous whitespace and intentional dividers.
- One bottom navigation only.
- Home is a calm dining experience, not an admin dashboard.

## V2 migration strategy
The existing V1 branch remains intact. V2 work begins on `v2-foundation` so the production main branch remains recoverable.

## First screen
Member Home is the visual benchmark. It should establish typography, spacing, navigation, meal presentation, buttons, alerts, loading, empty and error states before the design is propagated to Chef and Admin.
